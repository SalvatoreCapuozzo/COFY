COFY demo: one-command federation over the network, licence, online launchers

cofy_system/demo/run_demo.py: starts the real server and four client

processes on one machine, creates a room for kfm12, WBC or DENTEX with the

sequential or concurrent scheme, joins every node with its own small dataset,

runs training and calibration, and prints turns, uploads, calibration and

the server's developer-mode evaluation. Dashboards stay open with --keep-open.

cofy_system/demo/data/: six training and two validation images per node

and a small evaluation set for each use case, with each source's licence

(demo/data/README.md); make_demo_data.py rebuilds them from the study splits.

cofy_system/demo/COFY_demo.ipynb and .devcontainer/: run the demo on

Google Colab or GitHub Codespaces for free.

cofy/net/client_app.py: a node that finished training just before the

server opened the calibration phase left without calibrating, and the

barrier then waited for the heartbeat timeout; it now waits for the phase.

The federation code the demo runs (cofy/ and cofy/net/), the YOLO26

classic-head architecture and requirements.
